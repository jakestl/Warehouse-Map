GitHub Repository Backend

Store and sync map changes directly in your GitHub repo

How GitHub Shared Storage Works:

1. Upload this file as index.html to your GitHub repository and enable GitHub Pages.

2. Every visitor automatically loads the shared warehouse_it_map.json file from your repo in locked View Screen.

3. When you log in as admin / admin and click Save to GitHub, the app commits your updated warehouse_it_map.json straight to your repo via the GitHub API.

In GitHub, go to Settings → Developer settings → Personal access tokens → Fine-grained tokens, grant Contents: Read and write on your map repo, and paste the token here.
